# Okulistik - Online Eğitim Platformu

Modern bir eğitim platformu ara yüzü. İlkokul ve ortaokullar için online eğitim hizmeti sunan web uygulaması.

## Özellikler

- 📱 Responsive tasarım
- 🎨 Modern UI/UX
- ⚡ Hızlı performans
- 🌐 Çok dilli destek (Türkçe)
- 👨‍🎓 Öğrenci ve öğretmen ara yüzleri

## Teknolojiler

- React 18
- Vite
- Tailwind CSS
- PostCSS

## Kurulum

```bash
npm install
```

## Geliştirme

```bash
npm run dev
```

Tarayıcıda `http://localhost:3000` açılacaktır.

## Üretim Yapısı

```bash
npm run build
```
